# 1. 业务背景

## 1.1 需求描述

- 建设“宝宝记录”能力，为家长提供宝宝固定信息、成长、喂养、疫苗及脱敏信息的持续记录与查看入口。

## 1.3 目标结果

- 支持一个用户维护多个宝宝，并在需要的业务页面切换当前宝宝。
- 支持成长数据录入、百分位计算、列表展示及出生至 7 岁的成长曲线展示。
- 支持亲喂、瓶喂、辅食、换尿布、睡眠、吸奶、体温、用药、随心记等喂养记录。
- 支持后台配置疫苗接种时间、接种时间表、接种须知，并在小程序形成计划、详情和实际接种记录。
- 支持后台维护脱敏进度表，在宝宝固定信息及用户详情中沉淀敏宝相关数据。
- PC 用户详情统一形成成长档案、喂养档案、疫苗档案和脱敏档案。

## 1.4 本期范围

- PC 后台：系统配置中的业务配置、内容配置；用户详情中的宝宝信息及四类宝宝档案。
- 内容配置：疫苗接种时间、接种时间表、接种须知、脱敏进度表。
- 微信小程序：宝宝信息主页、个人信息、宝宝固定信息新增/编辑、成长曲线、喂养记录、疫苗记录及相关详情/表单页面。
- 数据联动：小程序保存宝宝、成长、喂养、疫苗数据后，同步更新对应列表及 PC 用户详情。

## 1.5 本期不做

- 不提供医疗诊断、疾病判断、用药建议或疫苗接种决策。
- 不接入医院、疾控机构、智能设备或第三方健康数据。
- 不提供医生在线问诊、处方、多级审批、批量导入及自动任务。

# 2. 关键业务规则

## 4.1 唯一性 / 并发性

- 每个宝宝生成唯一宝宝 ID，并关联唯一所属用户 ID；一个用户可维护多个宝宝。
- 每条成长、喂养、疫苗、脱敏记录均保存记录 ID、用户 ID、宝宝 ID、记录时间、创建时间和更新时间。
- 同一宝宝可在同一天保存多条同类型记录，不按日期或类型去重。
- 编辑时按记录 ID 更新原记录，不新增重复记录。
- 多端同时编辑同一条数据时，本期按最后一次成功提交结果覆盖。

## 4.2 字段定义

### 4.2.1 个人信息与宝宝固定信息

| 字段 | 必填 | 默认值/展示 | 规则 |
| --- | --- | --- | --- |
| 当前阶段 | 是 | 无 | 单选：宝宝已出生、怀孕中、备孕中 |
| 宝宝头像 | 否 | 默认头像 | 支持选择本地图片 |
| 宝宝昵称 | 是 | 无 | 最多 12 个字符；去除首尾空格后不可为空 |
| 出生日期 | 宝宝已出生时是 | 无 | 用于计算月龄、成长百分位及预计接种时间 |
| 宝宝性别 | 宝宝已出生时是 | 无 | 单选男宝、女宝 |
| 预产期 | 怀孕中时是 | 无 | 日期选择 |
| 宝宝是否过敏 | 否 | 关闭 | 开启后展示当前特配奶粉、已使用时间 |
| 当前特配奶粉 | 过敏开启后可选 | 无 | 单选：氨基酸、深度水解、适度水解、暂未使用奶粉、不了解 |
| 已使用时间 | 否 | 无 | 仅数字，最多 1 位小数，单位“月” |

- 新增页和已填写编辑页均可开启或关闭“宝宝是否过敏”。
- 关闭过敏开关后，隐藏当前特配奶粉和已使用时间，并清空本次未提交的敏宝字段值。
- 备孕状态不展示宝宝出生信息；怀孕状态至少维护预产期；宝宝已出生状态按表格规则维护固定信息。

### 4.2.2 成长记录

| 字段 | 必填 | 单位 | 规则 |
| --- | --- | --- | --- |
| 记录日期 | 是 | - | 日期选择，默认当前日期 |
| 身高 | 条件必填 | cm | 数字输入，最多2位小数 |
| 体重 | 条件必填 | kg | 数字输入，最多2位小数 |
| 头围 | 条件必填 | cm | 数字输入，最多2位小数 |
| 宝宝照片 | 否 | - | 支持上传图片 |

- 身高、体重、头围至少填写一项，否则不可保存。
- 添加/编辑页记录自动绑定进入页面时的当前宝宝。

### 4.2.3 喂养记录

| 类型 | 核心字段 | 列表展示 |
| --- | --- | --- |
| 母乳亲喂 | 时间、总时长、左侧时长、右侧时长、备注 | 总时长、左侧、右侧 |
| 母乳瓶喂/配方奶 | 时间、奶量、备注 | 奶量（ml） |
| 辅食 | 时间、辅食名称/内容、进食感受、备注 | 辅食名称或内容 |
| 换尿布 | 时间、状态及尿液/便便相关选项、备注 | 状态及已填写详情 |
| 睡眠 | 开始、醒来、总时长、备注 | 总时长、开始、醒来 |
| 吸奶 | 时间、总量、左侧量、右侧量、备注 | 总量、左侧、右侧（ml） |
| 体温 | 时间、体温值、备注 | 体温值（℃） |
| 用药 | 开始时间、药品名称/本次用量、备注 | 药品名称及已填写用量 |
| 随心记 | 开始时间、记录内容、图片 | 记录内容及图片 |

- 列表按记录时间倒序展示时间轴卡片，包含时间、相对时间、类型图标、类型名称、内容/数值和备注。
- 顶部日期区域支持周历展示及月历展开；分类汇总支持快速筛选当天对应类型记录。

### 4.2.4 疫苗接种基础配置

| 字段 | 必填 | 控件 | 规则 |
| --- | --- | --- | --- |
| 接种时间表 | 否 | 富文本编辑器 | 有内容时小程序展示入口；无内容时不展示 |
| 接种须知 | 否 | 富文本编辑器 | 有内容时小程序展示入口；无内容时不展示 |


### 4.2.5 疫苗接种时间配置

| 字段 | 必填 | 默认值 | 规则 |
| --- | --- | --- | --- |
| 月龄 | 是 | 无 | 单位“月”；仅数字；最多 1 位小数 |
| 接种疫苗名称 | 是 | 无 | 文本输入 |
| 疫苗介绍 | 否 | 无 | 文本输入；字段标签只显示“疫苗介绍” |
| 是否免费 | 是 | 是 | 单选按钮：是、否 |
| 顺序 | 是 | 当前列表末位 | 通过长按拖动调整，不单独展示顺序输入框 |

- 配置页一行展示一个配置项，支持新增、删除和长按拖动排序。

### 4.2.6 疫苗记录

| 字段 | 系统疫苗 | 自定义疫苗 | 规则 |
| --- | --- | --- | --- |
| 疫苗名称 | 后台配置带入 | 是 | 详情页可编辑 |
| 是否免费 | 后台配置带入 | 默认为否 | 展示免费/自费标签 |
| 是否自定义 | 否 | 是 | 系统记录，不由用户修改 |
| 接种时间 | 否 | 否 | 未填写时为空；点击添加；已填写时展示实际日期并可修改 |
| 备注 | 否 | 否 | 文本输入 |
| 疫苗介绍 | 后台配置带入 | 不展示 | 有配置时只读展示，无配置时不展示整个区域 |

- 点击疫苗卡片中的“完成接种”后，打开半屏接种时间选择器，默认选中当天；用户可修改实际接种日期。
- 点击“确定”且日期有效时，立即将疫苗标记为已完成，卡片接种时间由预计时间更新为实际时间，并生成或更新后台疫苗档案。
- 点击“取消”只关闭时间选择器，不修改完成状态、不写入后台记录。
- 添加自定义疫苗页提供返回和保存提交，保存后进入当前宝宝的疫苗记录。

### 4.2.7 脱敏进度表配置

| 字段 | 控件/规则 |
| --- | --- |
| 阶段代码 | 固定配置，可编辑 |
| 脱敏阶段 | 固定配置，可编辑 |
| 对应配方 | 固定配置，可编辑 |
| 推荐奶粉 | 固定配置，可编辑 |
| 当前奶粉类型 | 仅下拉选择：氨基酸、深度水解、适度水解、普通奶粉、成长奶粉、暂未使用奶粉、不了解 |
| 已使用奶粉时间 | 仅数字，最多 1 位小数，单位固定“月” |

- 使用系统预置配置行；编辑页只允许修改，不允许新增或删除。
- 阶段按预置顺序展示并保存。

### 4.2.8 PC 用户详情—宝宝档案记录

| 档案 | 展示字段 |
| --- | --- |
| 成长档案 | 记录时间、更新时间、宝宝昵称、身高、体重、头围；三项指标同时显示百分位值 |
| 喂养档案 | 记录时间、更新时间、宝宝昵称、类型、内容/数值、备注 |
| 疫苗档案 | 记录时间、更新时间、宝宝昵称、疫苗名称、是否免费、是否自定义、接种时间、备注 |
| 脱敏档案 | 记录时间、更新时间、宝宝昵称、当前阶段、当前奶粉、用奶时间 |

- 未填写值统一展示“-”，不得以 0 代替未填写状态。

## 4.3 计算规则

### 4.3.1 月龄与疫苗日期

- 宝宝月龄依据出生日期与业务日期计算；出生日期缺失时不计算实际月龄。
- 宝宝有出生日期：预计接种时间 = 宝宝出生日期 + 后台配置月龄。
- 宝宝无出生日期/月龄：预计接种时间 = 当前日期 + 后台配置月龄。
- 用户填写实际接种时间后，主页和详情展示实际时间，不再以预计时间替代。
- 自定义疫苗按用户添加或修改的日期展示。

### 4.3.2 疫苗排序

- 疫苗计划按后台拖动后的顺序升序展示；同月龄存在多条疫苗时仍按该顺序展示。

### 4.3.3 成长曲线与百分位

- 身高、体重、头围参考国家卫生健康委 WS/T 423—2022《7岁以下儿童生长标准》，按宝宝性别和测量月龄匹配参考值。
- 三类曲线横坐标统一为“出生～7 岁”，展示 3%、15%、50%、80%、97% 五条百分位线；15%、80%按相邻标准百分位插值展示。
- 用户记录按日期升序连线；某指标为空时不参与对应曲线。
- 头围标准参考值仅覆盖 0～3 岁；横坐标仍展示至 7 岁，但 3 岁后不展示参考线、不计算头围百分位。
- 成长记录列表仅展示百分位数值。
- 评价区间：大于 97%为过高；大于 85%且不高于 97%为偏高；15%～85%为正常；不低于 3%且低于 15%为偏低；低于 3%为过低。
- 边界值 3%、15%、85%、97%按上述包含关系执行；曲线和评价仅用于趋势参考，不构成医疗诊断。

## 4.4 关键联动逻辑

### 4.4.1 宝宝信息与切换

- 宝宝信息主页支持新增多个宝宝并切换当前宝宝。
- 喂养记录、成长曲线和疫苗记录在顶栏下展示当前宝宝头像、昵称、性别和月龄。
- 仅一个宝宝时不展示“选择”；多个宝宝时展示“选择”。
- 选择其他宝宝后刷新当前页列表、曲线或疫苗计划；不得跨宝宝混合数据。

### 4.4.2 记录数据联动

- 添加/编辑成长记录成功后，刷新列表和三类曲线，重新计算百分位及评价。
- 任一喂养类型保存成功后，记录立即出现在所选日期的时间轴，更新顶部汇总。
- 疫苗基础富文本保存后，小程序按内容是否为空控制入口；点击入口进入独立详情页。
- 疫苗配置保存后，小程序刷新系统计划和预计日期。
- 删除宝宝档案时同步删除该宝宝成长、喂养记录、疫苗及脱敏数据。

## 4.5 异常处理规则

- 成长标准不存在对应年龄数据时，不展示百分位和评价，以“-”表示。
- 当前宝宝被删除或不存在时，切换至剩余第一个宝宝；无宝宝时进入新增宝宝引导。

## 4.6  时效与有效期（按需）

- 预计接种日期随宝宝出生日期或后台月龄配置变化重新计算；已有实际接种时间不得自动覆盖。
- 记录时间为业务发生时间，创建时间为首次保存时间，更新时间为最近一次保存时间。
- 本期未设置成长、喂养、疫苗和脱敏记录的失效时间。

## 4.7 数据来源（按需）

- 宝宝固定信息、成长、喂养、实际疫苗记录：小程序用户保存。
- 疫苗计划、疫苗介绍、接种时间表、接种须知、脱敏进度表：PC 内容配置。
- 成长参考值：国家卫生健康委 WS/T 423—2022《7岁以下儿童生长标准》。

## 4.8 上限与极限（按需）

- 宝宝昵称最多 12 个字符。
- 宝宝已使用特配奶粉时间最多 1 位小数，单位月。
- 疫苗配置月龄最多 1 位小数，单位月。
- 脱敏进度表已使用奶粉时间最多 1 位小数，单位月。
- 用户宝宝数最多5个。
- 单日记录数最多1000条。

# 5. 状态与异常

## 5.1 业务状态

- 宝宝阶段：备孕中 / 怀孕中 / 宝宝已出生。
- 过敏状态：未开启 / 已开启。
- 疫苗：未完成接种 / 已完成接种；未填写接种时间 / 已填写接种时间；系统配置 / 用户自定义；免费 / 自费。
- 成长评价：过高 / 偏高 / 正常 / 偏低 / 过低 / 无法计算。

## 5.2 页面默认态

- 默认选中最近使用的宝宝；无历史选择时选中第一个宝宝。
- 成长曲线默认展示记录列表和身高曲线，范围为出生至 7 岁。
- 疫苗按后台配置顺序展示，无实际接种时间时展示预计时间。
- 喂养记录默认展示当前日期、周历、当日汇总和时间倒序列表。
- 疫苗“是否免费”默认“是”；自定义疫苗默认不免费；宝宝是否过敏默认关闭。

## 5.3 空态

- 无宝宝：展示新增宝宝引导，不展示业务记录列表。
- 无成长记录：展示空态及首条记录入口，曲线不绘制用户折线。
- 无喂养记录：展示“还没有喂养记录”及底部记录入口。
- 疫苗富文本为空：不展示对应入口；无疫苗计划：展示暂无接种计划。
- PC 各档案无数据：展示“暂无相关记录”，不使用虚构值。

## 5.4 异常态 / 失败态

- 百分位无法计算：仅展示测量值，百分位展示“-”。

## 5.5 权限态 / 不可操作态

- 脱敏进度表不可新增、不可删除，只可修改现有行。
- 仅一个宝宝时隐藏“选择”；喂养主页宝宝信息始终不可点击切换。

## 5.6 状态-操作矩阵（按需）

| 状态 | 可执行操作 | 结果/限制 |
| --- | --- | --- |
| 无宝宝 | 新增宝宝 | 不可新增成长、喂养、疫苗记录 |
| 单个宝宝 | 查看当前宝宝记录 | 不展示“选择” |
| 多个宝宝—成长/疫苗 | 打开选择、切换宝宝 | 不跨宝宝混合数据 |
| 疫苗主页—未完成接种 | 点击“完成接种”、选择实际接种日期、确定 | 写入实际时间，更新为已完成并同步 PC 疫苗档案 |
| 完成接种时间选择器 | 修改日期、确定或取消 | 确定后写入；取消不产生数据变化 |
| 疫苗详情—接种时间为空 | 点击添加日期、填写备注、保存 | 详情页不单独显示“完成接种”字段 |
| 疫苗已有接种时间 | 点击修改日期、编辑备注、保存 | 预计时间不覆盖实际时间 |
| 疫苗介绍为空 | 编辑其他详情、保存 | 不展示介绍模块 |
| 脱敏配置表 | 编辑现有行、保存 | 不允许新增或删除 |

## 5.7 状态流转（按需）

- 过敏关闭 → 开启：展示当前特配奶粉和已使用时间。
- 过敏开启 → 关闭：隐藏并清空敏宝字段，保存后更新宝宝信息。
- 疫苗时间为空 → 已填写：选择日期并保存，生成或更新疫苗档案。
- 疫苗时间已填写 → 修改：重新选择日期并保存，更新原记录。
