# 分销体系需求文档

---

## 1. 业务背景

### 1.1 需求描述

为激励 C 端用户进行商品分享和用户裂变，平台需建立完整的分销业务闭环。用户可申请成为分销员，通过分享分销商品建立客户绑定关系；被绑定用户完成有效订单后，系统按佣金规则计算并结算佣金；分销员完成认证签约后，可选择已结算订单申请提现。

本需求同时补齐支撑分销业务所需的用户管理、订单管理、页面装修及微信小程序页面，使分销关系、商品规则、业绩、提现、用户与订单数据能够相互追溯，并保持 PC 后台与微信小程序的数据一致。

### 1.3 目标结果

1. 建立团长、团员两类分销员的申请、审核、归属、等级和操作日志机制。
2. 支持按商品组和团长等级配置比例佣金或固定佣金，并控制规则生效时段。
3. 建立用户与分销员的长期或短期绑定关系，支持解绑、换绑及历史追溯。
4. 按分销员统计销售额、已发佣金和待发佣金，并可下钻至订单详情。
5. 打通实名认证、银行卡验证、协议签约、人脸识别、提现申请、后台审核和打款状态同步流程。
6. 补齐用户、订单、业绩和提现数据的导入导出能力，满足运营及财务核对需要。

### 1.4 本期范围

- 新增一级菜单：分销体系
- 新增二级菜单：分销体系-分销关系、分销体系-分销规则、分销体系-分销业绩、分销体系-佣金提现
- 商城装修：页面跳转-固定页-新增“分销推广”的跳转配置。
- 用户中心：用户管理列表、用户详情、用户导入解析、用户数据导出。
- 订单中心：订单管理列表、订单详情、订单维度导出、订单商品维度导出。
- 分销体系：分销员关系、用户绑定关系、分销员招募规则、分销员等级、分销商品组、佣金规则、分销业绩、分销数据详情、佣金提现、提现单详情。
- 微信小程序：加入分销、分销规则详情、我的分销、绑定用户明细、分销订单明细、分销商品、商品详情及分享、分销管理、认证签约、人脸识别、收益明细、提现、选择订单、申请提现和提现明细。
- 商品创建及普通下单沿用现有商城逻辑；本期仅补充与分销相关的商品选择、佣金计算、订单标记和数据展示。

### 1.5 本期不做

- 不改造现有商品创建、购物车、结算及普通下单主流程。
- 不回溯重算规则生效前已完成订单的佣金。
- 不因分销员换绑、升级或更换客商而修改历史订单归属。
- 不支持团长降级为团员。

---

## 2. 关键业务规则

### 4.1 唯一性 / 并发性

- 用户手机号全局唯一；导入或新增用户时，已注册手机号不得重复创建。
- 分销员手机号必须对应系统内已注册用户；同一用户只能存在一条有效分销员身份记录。
- 分销员分为团长、团员。一个团长可绑定多个团员，一个团员同一时刻只能归属一个团长。
- 团员可升级为团长；团长不可修改为团员。
- 分销员等级名称不可重复，等级按销售额门槛从低到高匹配。
- 同一商品组在同一生效时段只能关联一条佣金规则；新增、复制或编辑时发现时段重叠，应阻止保存并提示冲突规则。
- 佣金规则创建成功后，生效开始时间不可编辑；其他可编辑项仅影响修改后新产生的订单。
- 同一分销订单只能被一笔有效提现申请占用。订单进入待审核或打款中后，不得再次选择；审核拒绝或打款失败后可重新进入可提现订单池。
- 财务回调以提现单号作为幂等键。同一提现单重复收到相同结果时不得重复变更佣金、收益或日志。
- 多人同时审核同一提现单时，仅首次针对“待审核”的提交有效；后续提交提示状态已变化并刷新详情。

### 4.2 字段定义

#### 4.2.1 分销员关系

- 分销员信息：展示名称、分销员 ID、手机号；名称可点击进入用户详情。分销员名称：默认为昵称，微信小程序“分销管理”当前页可修改；必填，最多 30 个字。保存后同步分销关系、分销订单、提现申请及分销二维码海报名。
- 类型：团长、团员，使用标签展示。
- 归属团长：仅团员展示。
- 团长等级：仅团长展示；待审核记录展示“-”。
- 团员数：仅团长展示，可点击打开团员明细。
- 申请时间：记录申请提交时间。
- 审核时间：同一单元格展示审核人及审核时间；未审核展示“-”。
- 审核状态：待审核、通过、拒绝。

#### 4.2.2 添加分销员

- 分销员手机号：必填，必须为系统内已注册的 11 位手机号，否则不可添加。
- 分销员类型：默认团长，可选团长、团员。
- 归属团长：下拉框支持按团长名称、ID、手机号模糊搜索，团员类型必填。


#### 4.2.3 分销员招募规则

- 基础规则字段顺序：分销引导图、分销规则、分销员开通审核。
- 分销引导图：系统默认提供一张图；支持查看、删除和重新上传。
- 分销规则：非必填，使用富文本编辑；微信小程序加入分销页存在规则时展示“点击查看分销规则详情”。
- 分销员开通审核：必填，单选“人工审核”或“自动开通”。
- 统计结算规则字段顺序：分销员等级销售额统计、用户绑定时效、佣金结算周期。
- 分销员等级销售额统计：必填，可选“仅团长”或“团长及团员”；用于判断团长等级。
- 用户绑定时效：必填，可选“长期绑定”或“短期绑定 N 天”；短期到期后，用户再次通过分销链接访问时可重新建立关系。
- 佣金结算周期：必填，订单完成后 N 天结算；填写 0 表示订单完成后立即结算。
- 协议规则分为“加入分销协议”和“提现相关协议”，两类均可添加多条。
- 协议名称：必填，最多 30 个字。
- 协议内容：必填，富文本编辑；不提供上传富文本文件入口。
- 协议列表字段：协议名称、协议内容、更新时间、操作；操作仅保留编辑、删除。

#### 4.2.4 分销员等级

- 等级名称：必填，最多 20 个字符，不可重复。
- 等级门槛销售额：必填，大于等于 0，最多保留两位小数。
- 支持新建和编辑；团长销售额达到门槛后自动匹配对应等级。团长等级销售额统计需与分销员规则选择的一致

#### 4.2.5 用户绑定关系

- 用户信息：展示头像、昵称、用户 ID、手机号；用户可点击进入用户详情。
- 绑定分销员：展示名称、分销员 ID、手机号。
- 绑定时间：展示实际绑定时间，并展示绑定时效“长期有效”或“短期绑定 N 天”。
- 绑定时效：来源于分销员招募规则；绑定期内展示“绑定中”，解绑、换绑或到期后展示“已解绑”。
- 操作：解绑、换绑、日志。换绑只影响后续订单，历史订单不回溯。

#### 4.2.6 分销商品

- 列表支持按分组名称、分组ID搜索。
- 列表字段：商品组名称、分组商品、创建人及创建时间、更新人及更新时间、操作。
- 新建/编辑商品组仅维护分组名称和商品，分组名50字内，分组商品可添加已上架的全部商品。
- “分组商品”可点击查看商品明细，并可继续添加商品。
- 商品选择支持按商品名称、商品类型、商品 ID、品牌、所属 SPU、分类、创建方式搜索。
- 商品字段：商品名称、SPU、品牌、分类、商品来源、发货仓、售价、API 商品编码、总库存、访客数、访问量、销量、虚拟销量、创建时间、更新时间、状态。
- 商品组未关联任何佣金规则时可删除；存在关联规则时禁止删除，并提示需先解除佣金规则关联。

#### 4.2.7 佣金规则

- 规则名称：必填，支持搜索。
- 生效时间：必填，包含开始时间和结束时间；可配置长期生效。
- 佣金模式：必填，固定佣金或比例佣金，支持搜索。
- 商品组：必填，下拉多选，可按名称搜索。
- 佣金设置：按团长等级配置团长佣金和团员佣金。
- 固定佣金单位为“元”；金额大于等于 0，最多保留两位小数。
- 比例佣金单位为“%”；数值范围 0～100，最多保留两位小数。
- 状态字段，状态为未生效、生效中、已失效。
- 创建时间、更新时间均展示操作人及时间。
- 固定佣金说明：单规格商品佣金＝固定佣金×购买数量；多规格商品购买规格 1 时佣金＝固定佣金×购买数量；购买其他规格时佣金＝（固定佣金－规格单价差价）×购买数量。
- 比例佣金说明：佣金＝实付单价（不含税费、运费、优惠等）×佣金比例×购买数量。

#### 4.2.8 用户管理与导入导出

- 用户列表新增搜索条件“是否分销”和“绑定分销员”，是否分销默认全部，绑定分销员支持模糊搜索。
- 用户列表在注册时间前新增“绑定分销员”。
- 来源渠道为邀请码时，邀请人展示“用户昵称（邀请码：12345）”。
- 点击用户昵称进入用户详情；用户详情增加展示分销信息。
- 用户导出基础信息增加 是否分销、绑定分销员
- 用户导入弹窗分为上传文件、解析确认、导入完成三步；解析拒绝记录排在前面。
- 导入模板字段：手机号、来源渠道、邀请渠道、邀请码、邀请人、用户性别、用户生日、当前阶段、预产期、偏好品牌、用户标签、所在群组、unionId、企业微信客户 userId。
- 手机号必填；其余字段非必填。手机号必须为正确的 11 位手机号，且不得为已注册手机号。
- 来源渠道可填邀请码、小程序、推广码、H5活码、后台导入、分销码。
- 邀请渠道可任意填写。
- 邀请码只能填写已注册用户的真实邀请码；填写邀请码后，邀请人自动取邀请码关联用户昵称，不允许手工填写。
- 未填写邀请码时，邀请人可任意填写。
- 用户性别仅可填男、女；用户生日和预产期格式为 YYYY-MM-DD；当前阶段仅可填已出生、孕期、备孕。
- 用户标签填写标签 ID，需校验存在；所在群组填写群组 ID，需校验存在。
- unionId、企业微信客户 userId、偏好品牌可任意填写。
- 上传提示固定为：“导入请查看模版导入说明。‘手机号’为必填项；邀请码、标签ID、群组ID需填写真实ID”。

#### 4.2.9 订单管理

- 分销信息字段：分销 ID、分销员、分销员手机号、佣金。
- 商品信息新增商品佣金。
- 订单维度导出新增分销员ID、分销员、分销员手机号、订单佣金
- 订单商品维度导出新增商品佣金

#### 4.2.10 分销业绩

- 数据统计：销售额、已发佣金、待发佣金。
- 分销员列表字段：分销员信息、销售额、已发佣金、待发佣金、操作。
- 点击分销员进入用户详情；操作“订单明细”进入分销数据详情，并自动带入当前分销员筛选。
- 分销数据详情搜索：订单号、用户信息、分销员、订单状态、发放状态、关联提现单。
- 明细字段：分销订单、下单用户、分销员、订单金额、佣金、关联提现单、发放状态。
- 点击分销订单号进入订单详情；点击下单用户或分销员进入用户详情。

#### 4.2.11 佣金提现

- 列表搜索：提现单/用户、提现状态。
- 列表字段：提现单号、申请用户、提现金额、提现手续费、预估个人所得税、收款银行卡、申请时间、提现状态、操作。
- 提现状态：待审核、审核拒绝、打款中、打款成功、打款失败。
- 提现详情为独立页面，展示当前状态流程、提交信息、审核记录、打款日志。
- 提交信息字段：提现单号、申请用户、完整用户手机号、申请时间、提现金额、提现手续费、预估个人所得税、预计到账、收款银行卡完整信息、关联订单数。
- 审核弹窗字段：提现单、申请用户、提现金额、手续费、预计到账、审核结果、审核意见。
- 审核结果使用单选。选择拒绝时审核意见必填；选择通过时审核意见选填。
- “提现明细”进入分销数据详情，并自动带入提现单号，只展示该提现单关联的分销订单。

#### 4.2.12 微信小程序加入分销

- 顶部展示后台配置的分销引导图；底部固定“申请加入”按钮。
- 存在分销规则时，在申请按钮上方展示“点击查看分销规则详情”，点击进入单独规则页。
- 存在加入分销协议时，提交前弹窗展示全部协议名称；用户必须逐条勾选后才可同意提交。
- 自动开通：提交成功直接进入“我的分销”。
- 人工审核：提交后按钮变为“审核中请耐心等待”；审核通过后再次进入直接跳转“我的分销”。
- 审核拒绝：进入页面时在分销规则下展示拒绝原因，并弹窗展示后台审核意见；关闭弹窗后允许重新申请。

#### 4.2.13 微信小程序我的分销与分销商品

- “我的分销”底部导航固定为分销业绩、分销商品、分销管理。
- 业绩数据按分销身份控制范围：团长统计本人及其直属团员的数据，团员仅统计本人数据。该范围统一作用于销售业绩、客户概况、订单概况及其明细；个人收益和提现仍仅按本人佣金计算。
- 销售业绩统计：今日销售、本月销售、今日到账佣金、本月到账佣金。
- 客户概况：客户数、今日新增。点击客户数进入当前身份数据范围内的全部绑定用户；点击今日新增时默认按当天绑定时间筛选。
- 订单概况按待付款、待结算、已结算、已退单统计；点击状态进入分销订单明细并自动带入状态筛选。
- 绑定用户明细支持按昵称、手机号、用户 ID 搜索，以及今天、昨天、近 7 天、近 30 天和自定义时间筛选。
- 绑定用户卡片第一行展示头像、昵称，昵称下展示 ID 和手机号，右侧展示绑定状态；下方展示绑定分销员名称、分销 ID、绑定时间和消费金额。绑定分销员信息取当前绑定关系记录。
- 分销订单明细支持按订单号、下单用户搜索，并按全部、待付款、待结算、已结算、已退单筛选。
- 订单卡片第一行展示可复制订单编号和状态；第二行展示商品主图、名称、单价、购买数量、商品佣金；第三行一行展示下单用户昵称、ID、手机号和下单时间、分销员名称和分销ID；第四行展示实付金额和佣金合计。点击订单卡片到现有的商品详情。
- 分销商品展示所有生效中佣金规则所关联商品，支持按商品名称、品牌、分类搜索。
- 商品列表单行展示主图、名称、规格、正常收脚、可赚佣金和分享按钮。
- 点击商品触控区进入商品详情；点击分享打开商品分享海报。
- 商品详情在底部分享入口上方展示“分享可赚 ¥x.xx”。
- 商品分享海报展示小程序名称、商品主图、商品价格、名称、推荐理由、小程序码；底部文案为“长按识别购买”“商品链接具有时效 YYYY.MM.DD HH:mm:ss 分享”。

#### 4.2.14 微信小程序分销管理与认证签约

- 分销信息，展示头像、分销ID、手机号及分销二维码。
- 分销员名称可在当前页编辑；必填，最多 30 个字，支持保存和取消。
- 团长在“分销信息”右侧展示“我的团员”入口，团员不展示该入口。点击入口进入独立的团员明细页。
- 团员明细仅展示当前团长直属且审核通过的团员，默认按加入时间倒序排列；支持按昵称、手机号搜索。
- 团员明细每条展示默认头像、昵称、分销员 ID、手机号、加入时间、绑定客户数和累计销售额；无数据或无匹配结果时展示固定缺省图标及对应提示。
- 绑定客户数仅统计当前绑定关系仍生效的客户：客户须仍归属该团员，且处于规则约定的有效绑定期内；已解绑、已换绑及绑定已到期的客户不计入。
- 点击分销二维码展示分享海报；顶部文案为“扫码注册购买享受优惠”，说明为“长按识别二维码”。
- 认证签约列表展示实名认证状态和提现银行卡验证状态。
- 认证签约详情以通栏列表填写身份证姓名、身份证号码、开户银行、银行卡卡号、银行预留手机号。
- 页面展示后台配置的全部提现相关协议，用户必须逐条勾选后才可提交认证。
- 提交认证后调中台接口校验全部通过则返回分销管理；失败则弹窗展示具体失败原因。
- 人脸识别展示认证状态、最近认证时间、认证有效期和认证照片。照片一行展示，点击图片可上传。
- 未认证时按钮为“去认证”；已认证或到期时按钮为“重新认证”。重新认证前未新增或未更新照片时，提示“照片未更新”。
- 个人分销员每半年需完成一次人脸识别。

#### 4.2.15 微信小程序收益与提现

- 收益明细顶部展示待结算佣金、可提现佣金和提现入口。
- 收益类型包含订单结算佣金、订单售后扣佣金、佣金提现。
- 点击订单结算佣金或订单售后扣佣金，进入分销订单明细并自动带入对应订单号。
- 佣金提现记录展示：状态、提现金额、提现单号、银行名称、银行卡号、提现时间、“查看提现明细”。
- 提现状态为“审核拒绝”时，收益明细列表在提现时间下方展示“拒绝原因”，内容取后台审核意见；状态为“付款失败”时展示“失败原因”，内容取财务中台打款失败回调。原因支持换行完整展示。
- 提现明细展示提现单号、提现状态、提现金额、提现银行名称、完整银行卡号、姓名及全部关联订单；关联订单不展示订单状态。
- 提现“选择订单”和“提现明细”中的每条订单均展示分销员名称、分销 ID；字段数据取订单生成时记录的分销归属，不随分销关系后续调整而回溯变更。
- 提现明细状态为“审核拒绝”或“付款失败”时，在提现概要区分别展示完整的拒绝原因或失败原因，并与收益明细列表使用同一数据源。
- 提现页展示已认证银行卡；无认证通过银行卡时，点击箭头进入认证签约；有认证银行卡时展示银行名称和尾号，点击进入认证签约并显示完整银行信息。
- 提现订单入口使用主色，展示已选订单数；选择订单页只展示未提现订单，支持单选和全选。
- 提现说明固定为：
  - “— 提现须知 —”
  - “提现前需完成实名认证、银行卡验证、协议签约和有效期内的人脸识别。”
  - “佣金将扣除综合服务费及依法计算的税费，多供应商订单合并提现将自动为多个提现单进行提现。”
  - “提交后可在收益明细-佣金提现中查看提现结果。”
  - “更多须知详见《提现协议1》《提现协议222》”，协议名称按后台实际配置展示。
- 申请提现确认页展示计提佣金、综合服务费、预估个人所得税、预计到账、到账账户和按供应商拆分数量。

#### 4.2.16 商城装修-页面装修

- 跳转类型选择“固定页”时，可选：首页、我的、购物车、全部分类页、订单列表、我的优惠券、积分商城、分销推广。

### 4.3 计算规则

- 销售额：统计有效分销订单实付金额；已取消、已退单或无有效分销关系的订单不计入。
- 已发佣金：发放状态为“已发放”的佣金合计。
- 待发佣金：发放状态为“待发放”的佣金合计。
- 今日/本月数据：分别按自然日和自然月，以订单完成、佣金到账的实际业务时间统计。
- 等级销售额：按招募规则选择的统计维度计算；“仅团长”只累计团长本人销售额，“团长及团员”累计团长及其团员销售额。
- 佣金结算：订单完成时间＋结算周期到期后，由待发放转为已发放；订单退款或取消不发放。
- 提现手续费：提现金额×综合服务费率；当前原型费率为 3%。
- 预估个人所得税：优先取汇税通税金计算结果；无接口结果的原型数据按（提现金额－提现手续费）×3%估算。
- 预计到账金额＝提现金额－提现手续费－预估个人所得税，最低为 0 元。
- 按供应商拆单：一次申请包含多个供应商订单时，按供应商分别生成提现单，各自保存订单清单、手续费、税额和到账金额。
- 对公计提按 1% 计提增值税；对私不计提增值税。个人所得税仍以汇税通返回结果为准。
- 负数提现：售后冲销导致提现金额为负时，对公代开自动切换为自开模式；前端不得允许用户主动选择负数订单提现。

### 4.4 关键联动逻辑

- 平台分销邀请入口申请默认团长；通过团长邀请入口申请默认团员并带入归属团长。
- 分销审核可修改申请类型；选择团员时必须选择归属团长，选择团长时隐藏归属团长字段。
- 分销员名称、类型、归属团长、等级变化后，相关列表、用户详情和小程序展示同步更新；历史订单归属不变。
- 用户通过有效分销链接、小程序码或海报访问后建立绑定关系；短期绑定到期后允许通过新的分销入口重新绑定。
- 商品只有同时属于商品组且存在生效中的佣金规则时，才在小程序分销商品中展示并产生佣金。
- 商品组、佣金规则发生变更时，小程序分销商品列表实时读取当前生效数据；失效规则商品立即下架。
- 有效绑定用户完成含佣金商品的订单后，订单写入分销员、佣金、发放状态，并同步销售业绩、交易概况和订单明细。
- 订单完成且达到结算周期后，系统调用财务中台计提接口；接口不实时返回计提订单号时，通过计提订单查询接口补齐状态。
- 提交提现前校验实名认证、银行卡验证、协议签约、账户授权和半年内人脸识别；任一项不满足时跳转对应处理页。
- 提交提现后，选中订单从可提现池移除；审核拒绝或打款失败后解除占用，重新进入可提现池。
- 后台审核通过后提现单真实更新为“打款中”，并同步小程序为“付款中”；财务回调后真实更新为“打款成功”或“打款失败”，同步收益、提现记录、业绩汇总和打款日志。
- 客商在计提后、提现前发生变更时，提现使用最新客商；发票主体必须为最新客商。

### 4.5 异常处理规则

- 手机号不存在、格式错误或已注册时，添加分销员/用户导入失败，并展示具体行号和原因。
- 邀请码、标签 ID、群组 ID 不存在时，对应导入记录标记解析拒绝；不得部分写入错误记录。
- 团员未选择归属团长时禁止提交；所选团长已失效或不存在时提示重新选择。
- 佣金规则时间与同一商品组现有规则重叠时禁止保存，并提示冲突规则名称及生效时间。
- 删除已被佣金规则引用的商品组时禁止删除。
- 固定佣金减去规格单价差价后小于 0 时，该规格佣金按 0 计算，不产生负佣金。
- 订单取消、全额退款时佣金归零；已结算后发生退款时生成“订单售后扣佣金”负向收益记录。
- 提现银行卡无效、协议未勾选、人脸识别过期或照片未更新时禁止提交并提示处理方式。
- 税金计算失败时不得提交提现，保留已选订单并允许重试。
- 财务回调失败时提现单更新为“打款失败”，保存失败原因；关联订单解除占用，可重新提现。
- 页面数据加载失败展示错误态和“重新加载”；重新加载不得清除当前筛选条件。
- 导出无数据时不生成空文件，提示“当前筛选条件下暂无可导出数据”。

### 4.6 权限规则（按需）

- 分销员关系查看：运营管理员或具备对应菜单权限的角色可用。
- 分销员审核、编辑、换绑、解绑、等级配置、招募规则及佣金规则配置：运营管理员或具备对应菜单权限的角色可用。
- 佣金提现审核：运营管理员或具备对应菜单权限的角色可用。
- 打款结果只允许财务中台回调或财务管理员通过受控接口写入，列表不提供手工修改入口。
- 用户导入导出、订单导出、业绩导出和提现导出需独立数据权限。
- 敏感字段默认脱敏；用户详情、提现详情和导出中的完整手机号、身份证、银行卡号仅对具备敏感信息权限的角色展示。

### 4.7 时效与有效期（按需）

- 短期绑定按绑定时间起算 N×24 小时；到期自动失效。
- 佣金规则按配置的开始时间和结束时间判断状态；长期有效规则无结束时间。
- 订单佣金按订单完成时命中的规则快照计算，不受后续规则编辑影响。
- 个人分销员人脸识别有效期为最近一次认证通过后 6 个月。
- 分销及提现协议授权记录至少保存 3 年。
- 商品分享链接包含有效期；过期后打开时提示链接已失效，不建立绑定关系。

### 4.8 数据来源（按需）

- 用户、标签、群组、邀请关系：用户中心。
- 商品、SPU、品牌、分类、仓库、库存和商品状态：商品中心。
- 订单、支付、售后、实付金额、税费和运费：订单中心。
- 分销关系、绑定关系、等级、商品组、佣金规则、业绩和佣金：分销体系。
- 客商信息及实人认证：主数据平台。
- 银行卡四要素：阿里云银行卡四要素校验。
- 计提、营收结算单、提现单和付款结果：财务中台；SAP 负责计提凭证。
- 个人所得税：汇税通税金计算查询接口。

### 4.9 通知机制（按需）

- 分销员申请审核通过或拒绝后，微信小程序下次进入时展示最新状态；拒绝需展示审核原因。
- 提现审核通过、审核拒绝、打款成功、打款失败后同步小程序收益明细和提现记录。
- 财务中台通过“提现订单/开票状态变更通知”回调平台；平台每天对未终态提现单调用提现单分页查询接口主动补偿查询。
- 回调或主动查询得到新状态时，记录来源、时间、原状态、新状态和失败原因。

### 4.10 上限与极限（按需）

- 分销员名称最多 30 个字。
- 分销等级名称最多 20 个字符。
- 分销规则富文本最多 1000 字；协议正文长度待确认。
- 用户导入文件支持 `.xlsx`、`.xls`、`.csv`，单文件最大 10MB。
- 佣金比例范围 0～100；金额类字段最多保留两位小数。
- 单次提现可选订单数、单次提现金额上下限、日/月提现次数待财务确认。
- 单个商品组商品数、单条佣金规则商品组数、单次导出最大数据量待确认。

## 5. 状态与异常

### 5.1 业务状态

- 分销申请：待审核、通过、拒绝。
- 用户绑定：绑定中、已解绑；已解绑原因包含主动解绑、换绑、短期到期。
- 佣金规则：未生效、生效中、已失效。
- 分销订单：待付款、待结算、已结算、已退单。
- 佣金发放：待发放、已发放。
- 提现单：待审核、审核拒绝、打款中、打款成功、打款失败。
- 认证签约：未认证、认证通过、认证未通过。
- 人脸识别：未认证、认证通过、已到期、认证失败。

### 5.2 页面默认态

- 所有列表首次进入默认展示全部数据，分页第 1 页；筛选项默认“全部”，文本搜索为空。
- 分销关系默认进入“分销员关系”页签；用户绑定关系为第二页签。
- 分销规则默认进入“分销商品”页签；佣金规则为第二页签。
- 用户导入默认处于“上传文件”步骤；解析确认页错误记录置顶。
- 我的分销默认进入“分销业绩”；收益明细默认进入“全部”。
- 绑定用户明细默认按绑定时间倒序；从“今日新增”进入时默认选择“今天”。
- 分销订单明细默认展示全部状态；从交易概况进入时带入所点状态。

### 5.3 空态

- 列表无数据或筛选无结果时，在列表主体展示统一空态图标和对应文案，不保留模拟数据说明。
- 分销商品为空：展示“暂无可分销商品”。
- 绑定客户为空：展示固定空态图标和“暂无绑定客户”。
- 分销订单为空：展示“暂无分销订单”。
- 可提现订单为空：展示“暂无未提现订单”，确认按钮禁用。
- 协议列表为空：展示“暂无协议，请点击添加协议”。
- 审核记录或打款日志为空：表格展示“暂无审核记录”或“暂无打款日志”。

### 5.4 异常态 / 失败态

- 分销申请拒绝：展示后台审核拒绝原因，允许重新申请。
- 用户导入解析失败：展示错误字段、原始值和失败原因；错误记录不得导入。
- 认证失败：弹窗展示实名认证、银行卡四要素、协议或人脸识别的具体失败原因。
- 提现审核拒绝：收益明细列表和提现明细均展示审核意见，关联订单恢复可提现。
- 打款失败：收益明细列表和提现明细均展示财务返回失败原因，后台保留打款日志，关联订单恢复可提现。
- 商品或佣金规则失效：从旧分享链接进入时提示商品或规则已失效，不计算佣金。
- 网络或接口失败：保留页面输入、勾选项和筛选条件，提供重试入口。

### 5.5 权限态 / 不可操作态

- 待审核分销员不可编辑类型、等级或归属，只能审核、查看日志。
- 团长类型不展示归属团长，且不可降为团员。
- 已被佣金规则引用的商品组删除按钮不可用。
- 佣金规则开始时间创建后只读；已失效规则不可编辑。
- 非待审核提现单不展示审核操作；打款中仅展示详情、提现明细。
- 未完成认证签约或人脸识别无效时，提现提交按钮禁用并提示原因。

### 5.6 状态-操作矩阵（按需）

#### 分销员关系

| 审核状态 | 类型 | 可执行操作 | 备注 |
| --- | --- | --- | --- |
| 待审核 | 团长/团员 | 审核、日志 | 团长等级展示“-” |
| 通过 | 团长 | 日志 | 团长不可降为团员 |
| 通过 | 团员 | 编辑、日志 | 可升级团长或调整归属团长 |
| 拒绝 | 团长/团员 | 编辑、日志 | 用户可重新提交申请 |

#### 佣金规则

| 状态 | 可执行操作 | 备注 |
| --- | --- | --- |
| 未生效 | 编辑、删除、日志 | 开始时间不可编辑 |
| 生效中 | 编辑、立即失效、复制、日志 | 编辑只影响新订单 |
| 已失效 | 复制、删除、日志 | 不可恢复生效 |

#### 佣金提现

| 状态 | 可执行操作 | 订单占用 | 备注 |
| --- | --- | --- | --- |
| 待审核 | 审核、详情、提现明细 | 占用 | 可通过或拒绝 |
| 审核拒绝 | 详情、提现明细 | 释放 | 订单可重新提现 |
| 打款中 | 详情、提现明细 | 占用 | 不提供后台手工完成入口 |
| 打款成功 | 详情、提现明细 | 完成 | 终态 |
| 打款失败 | 详情、提现明细 | 释放 | 可重新发起提现 |

### 5.7 状态流转（按需）

- 分销申请：提交申请 → 待审核 → 通过 / 拒绝；拒绝 → 重新提交 → 待审核。
- 用户绑定：建立绑定 → 绑定中 → 已解绑；换绑后为旧关系已解绑、新关系绑定中。
- 佣金规则：保存且开始时间未到 → 未生效；到达开始时间 → 生效中；到达结束时间或立即失效 → 已失效。
- 佣金：订单完成 → 待发放；结算周期到期且无退款 → 已发放；售后退款 → 生成扣佣金记录。
- 提现：提交申请 → 待审核 → 审核拒绝 / 打款中；打款中 → 打款成功 / 打款失败。
- 认证签约：提交资料 → 实名认证 → 银行卡四要素验证 → 客商创建 → 协议签约 → 认证通过；任一步失败 → 认证未通过。
- 人脸识别：未认证 → 认证通过 → 6 个月后已到期 → 重新认证。

## 6. 衍生需求与默认授权项

### 6.1 导出

- 用户管理导出为一个 Excel 文件，包含两个 Sheet：`用户基本信息`、`用户宝宝信息`。
- 用户基本信息在附件模板字段基础上新增“是否分销、绑定分销员”；邀请来源为邀请码时，邀请人按“用户昵称（邀请码：12345）”导出。
- 订单管理支持订单维度导出和订单商品维度导出，字段与附件《订单维度导出.xlsx》《订单商品维度导出.xlsx》一致。
- 分销业绩导出字段：分销员、分销员 ID、分销员手机号、销售额、已发佣金、待发佣金。
- 分销数据详情导出字段：分销员、分销员 ID、分销员手机号、用户昵称、用户 ID、用户手机号、分销订单号、下单时间、订单状态、订单金额、佣金、佣金发放状态。
- 佣金提现导出基于当前搜索及状态筛选，字段顺序固定为：提现单号、申请用户、用户手机号、收款银行、银行卡号、申请时间、提现金额、提现手续费、预计到账金额、预估个人所得税、提现单状态、审核意见。
- 文件名建议：`模块名称_YYYYMMDDHHmmss.xlsx`；原型阶段佣金提现可生成 UTF-8 BOM CSV。
- 导出需记录操作人、筛选条件、导出时间和记录数；敏感信息按导出权限决定是否脱敏。

### 6.2 日志

- 分销员申请、审核、类型调整、归属团长调整、等级变更、解绑、换绑均记录操作日志。
- 分销员招募规则、等级、商品组和佣金规则的新建、编辑、删除、立即失效、复制均记录操作日志。
- 提现日志分为审核记录和打款日志；记录原状态、新状态、操作人/系统来源、时间、意见或失败原因。
- 财务回调和主动查询均需记录接口流水号，便于幂等校验与问题追踪。
- 用户导入记录文件名、上传人、解析结果、成功数、失败数和失败明细。
- 日志按时间倒序，时间格式统一为 `YYYY-MM-DD HH:mm:ss`。

### 6.3 ID 规则

- 用户 ID、分销员 ID、订单号、商品 ID、SPU、商品组 ID、佣金规则 ID、提现单号均全局唯一且不可编辑。
- 分销员 ID 示例：`D10001`；提现单号示例：`TX20260719001`；分销订单号示例：`FX20260804001`。
- 提现按供应商拆单时，每个子提现单生成独立提现单号，并保存同一批次号，批次号规则待确认。
- 导入校验使用标签 ID、群组 ID 和邀请码原值，不按名称模糊匹配。

### 6.4 通知

- 分销申请审核结果、提现审核结果和打款结果需在微信小程序回显；增加订阅消息通知。
- 佣金结算、售后扣佣金和提现状态变化需实时更新收益明细。
- 财务回调失败或连续主动查询异常时，应向财务/技术告警，告警渠道待确认。

### 6.5 默认授权项

- 默认仅管理员拥有全部菜单和操作权限。
- 微信小程序仅允许当前登录用户查看和操作本人分销、收益、认证和提现数据。
