# 1. 业务背景

## 1.1 需求描述
私域 SaaS 3.0 在保留独立租户能力的基础上新增品牌租户。品牌租户用于整合独立租户、公域电商平台、企微及品牌自身数据，统一消费者入口、OneID、商品池、营销与积分；独立租户继续承担商品供给、订单履约及独立核算。

## 1.2 产品定位
- 平台管理：管理租户权限、租户开通、租户接入关系及小程序授权。
- 品牌租户：统一小程序、统一用户、统一运营，并按接入范围使用独立租户能力。
- 独立租户：可独立经营；接入品牌后按授权范围提供商品、库存、履约、积分及优惠券能力。

## 1.3 目标结果
- 同一 SaaS 支持品牌租户与独立租户并行运营。
- 品牌租户与独立租户建立可配置、可解除的接入关系。
- 品牌侧用户通过 OneID 完成跨来源身份整合。
- 商品、订单、售后均可识别数据来源或实际发货平台。
- 用户、订单、售后导出字段与业务列表口径一致。

## 1.4 本期范围
- 租户权限：独立租户、品牌租户权限版本。
- 租户管理：租户模式、权限联动、租户详情、接入及解除接入。
- 小程序授权：支持品牌租户和独立租户小程序。
- 用户管理：接入平台、OneID、列表搜索、详情与导出。
- 商品管理：API 对接及租户同步商品、来源字段和只读限制。
- 订单管理：发货平台、完整搜索、列表与订单维度导出。
- 售后管理：发货平台、完整搜索、列表与售后导出。

## 1.5 本期不做
- 线下门店 SaaS、门店会员通用规则及加盟/直营组织模型。
- SCRM 自动化运营流程。
- 公域平台、企微真实接口开发及历史数据迁移执行方案。
- 多品牌间 OneID 合并冲突的自动裁决。

# 2. 关键业务规则

## 2.1 租户模式与权限
- 系统租户模式分为独立租户、品牌租户，新增租户默认选择独立租户。
- 选择独立租户时，只可选择独立租户权限版本；选择品牌租户时，只可选择品牌租户权限版本。

## 2.2 品牌租户接入独立租户
- 品牌租户可接入多个独立租户，每个独立租户分别配置接入范围。
- 可选接入范围：全部、商品库存、订单履约、积分优惠券。
- 选择“全部”后不可同时选择其他范围。
- 接入关系在品牌租户详情中查看和维护。
- 解除接入必须二次确认，提示：解除后，独立租户停止向当前品牌同步数据，之前接入数据不影响，后续可恢复接入。
- 解除后保留历史数据和历史关系记录，停止新增数据同步；后续允许重新接入。

## 2.3 租户新增、编辑与详情
- 基础信息新增租户模式。
- 列表新增租户模式搜索。
- 列表新增 租户模式。
- 操作包含编辑、详情、日志；品牌租户额外提供接入租户入口。

## 2.4 小程序授权
- 新增、编辑小程序时可选择所属租户，支持品牌租户与独立租户。
- 列表增加租户模式字段。

## 2.5 用户与 OneID
- 用户增加“接入平台”和“OneID”。接入平台显示租户名称，OneID 为品牌域统一身份标识。
- 列表及搜索新增接入平台、OneID。
- 用户详情在基础资料中展示接入平台、OneID，并保留宝宝信息、标签群组、收货地址及企微资料。
- 用户导出在既有字段基础上增加接入平台、OneID，按当前筛选结果导出。

## 2.6 商品来源与只读规则
- 商品来源包含手工创建、API 对接、某租户同步。
- 某租户同步商品不可修改供应商、API商品编码、发货仓；其他商品按原权限编辑。

## 2.7 订单管理
- 搜索新增发货平台。
- 列表增加发货仓。
- 订单维度导出共 33 个字段，最后一列为发货平台；按当前筛选结果导出。

## 2.8 售后管理
- 搜索新增发货平台。
- 列表增加发货仓。
- 售后导出共 26 个字段，最后一列为发货平台；按当前筛选结果导出。

## 2.9 数据同步与追溯
- 接入范围决定品牌租户可使用的独立租户能力，不代表删除或合并独立租户。
- 历史订单、售后与用户记录保留原发货平台或接入平台，解除接入不回溯删除。
- 品牌租户可查看已接入独立租户授权范围内的数据；独立租户保持本租户数据隔离。

# 4. 字段与联动规则

## 4.1 核心字段

| 字段 | 所属模块 | 必填 | 默认值 | 规则 |
| --- | --- | --- | --- | --- |
| 租户模式 | 租户 | 是 | 独立租户 | 单选：独立租户、品牌租户 |
| 版本类型 | 租户 | 是 | 无 | 与租户模式联动过滤 |
| 接入租户 | 品牌租户 | 是 | 无 | 支持选择多个独立租户 |
| 接入范围 | 接入关系 | 是 | 全部 | 每个独立租户单独配置 |
| 接入平台 | 用户 | 否 | - | 展示来源租户名称 |
| OneID | 用户 | 否 | - | 品牌域统一身份标识 |
| 商品来源 | 商品 | 是 | 手工创建 | API对接、某租户同步等 |
| 发货平台 | 订单/售后 | 否 | - | 展示实际履约租户名称 |

## 4.2 关键联动
- 租户模式不可变更。
- 接入租户新增或移除时，品牌详情中的接入关系即时刷新。
- 接入范围按独立租户保存，修改一个租户不影响其他租户。
- 用户、商品、订单、售后列表的搜索和导出使用同一筛选结果集。

# 5. 状态与异常

## 5.1 业务状态
- 接入关系：已接入、已解除。

## 5.2 页面默认态
- 租户模式默认独立租户。
- 接入范围默认全部。

## 5.3 空态
- 品牌租户未接入独立租户时展示接入空态和接入入口。

## 5.4 异常与限制
- 租户模式与版本类型不匹配时不可保存。

## 5.5 状态—操作矩阵

| 对象状态 | 可执行操作 | 限制 |
| --- | --- | --- |
| 品牌租户未接入 | 接入租户 | 仅选择独立租户 |
| 品牌租户已接入 | 查看、调整范围、解除接入 | 解除需二次确认 |
| 独立租户已解除 | 重新接入 | 历史数据不重复导入 |
| 同步商品 | 查看、上下架 | 供应商、API编码、发货仓只读 |
| 待发货订单 | 查看详情 | 发货平台不可为空时需展示 |

# 6. 权限、日志与导出

## 6.1 权限
- 平台管理员管理租户权限、租户、小程序授权及接入关系。
- 品牌租户管理员拥有用户、商品、订单、营销、积分、装修等品牌运营权限，并查看接入租户授权数据。
- 独立租户管理员保留本租户运营能力；接入品牌后的可操作范围由接入配置决定。

## 6.2 日志
- 租户新增、编辑、模式变更、版本变更、接入、调整接入范围、解除和恢复接入需记录日志。
- 日志字段：日志ID、操作人、操作描述、提示信息、操作时间。
- 日志按操作时间倒序展示。

## 6.3 导出
- 用户导出新增接入平台、OneID。
- 订单维度导出新增发货平台，共 33 个字段。
- 售后导出新增发货平台，共 26 个字段。
- 导出范围为当前页面筛选结果，文件名包含业务名称与时间戳。

## 6.4 数据安全
- 不同独立租户数据默认隔离。
- 品牌租户仅访问已接入且在授权范围内的数据。
- 解除接入不删除历史数据，但停止后续同步。

# 7. 验收要点

- 可分别配置品牌租户和独立租户权限版本。
- 新增租户时租户模式与版本类型正确联动。
- 一个品牌租户可同时添加多个独立租户并分别配置接入范围。
- 品牌租户详情可解除并重新接入独立租户，历史数据保持不变。
- 品牌租户和独立租户均可授权小程序，Logo 必传且支持预览小程序码。
- 用户列表、详情、搜索和导出均包含接入平台、OneID。
- 商品列表和详情不展示来源租户，同步商品指定字段不可修改。
- 订单和售后列表、搜索及导出均包含发货平台。
- 订单和售后日期范围均使用一个组合输入框。
- 所有搜索、清空、页签切换、详情、导出操作均基于页面模拟数据真实生效。
